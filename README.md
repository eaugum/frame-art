# Frame Art

Et Home Assistant-add-on som styrer Kunstmodus på Samsung The Frame: en egen rotasjon fra en mappe, museer,
Wikimedia Commons, NASA og film, med et morgenbilde (dato og vær) og kveldens serie fra Stasera.

[![Legg til repoet i Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Feaugum%2Fframe-art)

Eller: Innstillinger → Add-ons → Add-on Store → ⋮ → Repositories → `https://github.com/eaugum/frame-art`.

Add-on-et ligger i [`frame_art/`](frame_art/README.md), med valgene, kildene og API-et. `scripts/` er prøveskript
mot TV-en, til feilsøking.
